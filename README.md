# CampusHub AI 🎓

An AI-powered Smart Campus Ecosystem connecting Students, Teachers, and Administrators.

## 🚀 Overview

CampusHub is a full-stack platform designed to streamline campus management, academic collaboration, AI-assisted learning, doubt solving, and institutional analytics.

## 📁 Repository Structure

```
campus-hub-ai/
├── backend/       # Node.js / Express backend API (Doubt solver, auth, services)
├── frontend/      # React / Vite frontend application
└── package.json   # Monorepo task scripts
```

## 🛠️ Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/sudipc2004/CampusHub.git
cd CampusHub

# Install frontend dependencies
cd frontend
npm install

# Install backend dependencies
cd ../backend
npm install
```

### Running Locally

From the root directory:

```bash
# Start Frontend (React + Vite)
npm run dev:frontend

# Start Backend (Express API)
npm run dev:backend
```

## 🌟 Key Features

- **AI Doubt Solver**: Instant AI-powered assistance for academic queries.
- **Role-Based Portals**: Dedicated interfaces for Students, Teachers, and Admins.
- **Smart Analytics & Quizzes**: Real-time performance tracking and AI quiz generation.
- **Knowledge Base & Study Groups**: Collaborative learning hubs.
